# PadLink — النسخة 0.1

هاتفان: **هاتف الشاشة** (اللعبة عليه) و**هاتف الكيبورد** (أزرار + منطقة كاميرا).
التطبيق لا يلمس ملفات اللعبة إطلاقاً؛ فقط يضع لمسات على الشاشة عبر Shizuku.

## البناء (GitHub)
1. ارفع كل الملفات إلى مستودع GitHub كما هي في الجذر.
2. المجلد الوحيد المطلوب: `.github/workflows/build.yml`.
3. تبويب Actions ← Build APK ← حمّل `PadLink-debug-apk`.

الـ workflow هو من يرتّب الملفات داخل المجلدات وقت البناء، لذلك تبقى الملفات عندك مسطّحة.
(هذا الترتيب مخصص لبناء GitHub، وليس لفتحه مباشرة في أندرويد ستوديو.)

## التجهيز (هاتف الشاشة فقط)
1. ثبّت Shizuku وشغّله (Wireless Debugging على أندرويد 11+).
2. افتح PadLink ← «منح صلاحية Shizuku» ثم «منح العرض فوق التطبيقات».
3. «تشغيل الاستقبال» ويظهر لك عنوان IP.

## الاستخدام
1. الهاتفان على نفس الواي فاي (أو أحدهما يشغّل هوتسبوت).
2. على هاتف الكيبورد: اكتب IP هاتف الشاشة ← «اتصال».
3. على هاتف الشاشة: افتح اللعبة ← اسحب الإشعارات ← **تعديل الأزرار** ← اسحب كل رقم فوق زره في اللعبة (C = بداية سحب الكاميرا) ← **تم**.
4. العب: الضغط المستمر على الزر = لمس مستمر، والرفع = رفع اللمس.

## ملاحظات
- عدّل الأزرار والشاشة بنفس اتجاه اللعبة (أفقي عادةً).
- حساسية الكاميرا: الثابت `SENS` في `ReceiverService.kt`.
- إذا اشتكى Gradle من نسخة مكتبة Shizuku فاستبدلها بآخر نسخة من صفحة Shizuku-API.
