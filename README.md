# TwoPhone Pad — v0.1

نسخة أولية لتجربة الربط بين هاتف الشاشة وهاتف التحكم.

## البناء
يفتح GitHub Actions تلقائيًا عند push، أو يمكن تشغيل Build Android APK يدويًا من تبويب Actions. ينتج البناء ملف APK من نوع debug ضمن Artifact باسم TwoPhonePad-debug-apk.

## ملاحظات النسخة الأولية
- اتصال TCP مباشر بين الهاتفين على الشبكة المحلية.
- واجهة بسيطة لوضع الشاشة والتحكم.
- نقرات تجريبية عبر Shizuku بعد منح الصلاحية.
- لا تتم قراءة ملفات اللعبة أو تعديلها.
- محرر توزيع الأزرار والضغط المستمر وتحريك الكاميرا ما زالت غير مكتملة.
