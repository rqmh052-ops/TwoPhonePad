# PadLink — النسخة 0.3

هاتفان: **هاتف الشاشة** (اللعبة عليه) و**هاتف التحكم** (أزرار حرة + منطقة كاميرا).
كل شيء برمجي: واي فاي / هوتسبوت / بلوتوث — لا كابلات ولا ملحقات.

## الجديد في 0.3
- **إصلاح الانقطاع بعد ثوانٍ**:
  - هاتف التحكم صار يملك حارساً: لو لم يصله رد خلال 6 ثوانٍ يقطع ويعيد الاتصال تلقائياً (سابقاً كان الاتصال الميت يبقى معلّقاً).
  - تثبيت شبكة الواي فاي/الهوتسبوت حتى لو «بدون إنترنت» (طلب شبكة + ربط العملية بها) فلا يقطعها أندرويد 15 ولا يحوّل للبيانات.
  - هاتف الشاشة: WakeLock + WifiLock + خيار استثناء توفير البطارية + إعادة فتح المنافذ تلقائياً + إعادة بناء Shizuku لو مات.
  - **نقطة الإبقاء «1»** (اختيارية): مربع صغير جداً فوق التطبيقات يبقي النظام يعتبر التطبيق ظاهراً. فعّلها من تبويب «هاتف الشاشة».
  - شاشة الاستقبال تعرض «آخر انقطاع» وسببه، وأي خطأ في حقن اللمس.
- **أوضاع ضغط جديدة** (ضغطة مطولة على الزر في وضع التعديل ✎):
  - **ضغطة واحدة فقط**: نقرة قصيرة واحدة مهما طال إمساكك.
  - **ضغط مستمر**: يبقى مضغوطاً طالما ماسكه.
  - **ضغط مستمر + تصويب بالسحب ◎**: تطلق وتسحب إصبعك فيتحرك إصبع الزر على اللعبة بنفس الاتجاه (بحساسية الكاميرا نفسها).

## الجديد في 0.2
- واجهة جديدة بالكامل (داكنة، أزرار مرسومة مخصصة بدل أزرار النظام).
- أزرار حرة: اسحبها لأي مكان، وغيّر الحجم/اللون/الشكل/الاسم، أضف أزراراً (حتى 30) أو احذف أو انسخ.
- ضغطة مطولة على الزر (في وضع التعديل ✎) تفتح خيارات:
  - **عادي**: اضغط وأفلت.
  - **تبديل**: يبقى مضغوطاً حتى تضغطه مرة ثانية (مثل تثبيت زر الضرب).
  - **تكرار تلقائي ⚡**: يضغط ويرفع بسرعة وأنت ماسكه.
  - **تثبيت الضغط الآن / رفع التثبيت** لأي زر.
- زر 👁 يخفي كل الأزرار (تبقى تعمل) ونقطة صغيرة بالأعلى تُرجعها.
- من ⚙ الإعدادات: حساسية الكاميرا، الشفافية، وخيار «الضغطة المطولة تفتح القائمة أثناء اللعب» (متوقف افتراضياً حتى لا يتعارض مع الإمساك بالزر).
- اتصال قوي متعدد القنوات:
  1. **Wi-Fi / TCP** (نفس الشبكة أو هوتسبوت).
  2. **اكتشاف UDP Broadcast** تلقائي.
  3. **mDNS (NSD)** تلقائي.
  4. **فحص الشبكة والبوابة** (يلقط هاتف الهوتسبوت حتى لو فشل البث).
  5. **Bluetooth RFCOMM** (بدون واي فاي إطلاقاً).
  - رمز **PIN** للحماية، نبض Ping كل ثانيتين مع عرض التأخير بالـ ms، إعادة اتصال تلقائية، ورفع كل الأزرار تلقائياً لو انقطع الاتصال.
- هاتف الشاشة يعرض كل عناوين IP (واي فاي/هوتسبوت)، المنفذ، الـ PIN، اسم البلوتوث، حالة كل قناة، والجهاز المتصل.

## البناء (GitHub)
1. ارفع كل الملفات إلى مستودع GitHub في الجذر كما هي (ومعها `ic_launcher.xml`).
2. المجلد المطلوب: `.github/workflows/build.yml`.
3. Actions ← Build APK ← حمّل `PadLink-debug-apk`.

## التجهيز (هاتف الشاشة)
1. شغّل Shizuku (Wireless Debugging).
2. افتح PadLink ← تبويب «هاتف الشاشة»: امنح Shizuku + العرض فوق التطبيقات + البلوتوث.
3. «تشغيل الاستقبال» ← سيظهر لك الـ IP والـ PIN.
4. «تعديل أماكن الأزرار على اللعبة» ← افتح اللعبة ← اسحب كل رقم فوق زره ← «تم ✓».
   (أي زر جديد تضيفه على هاتف التحكم يظهر هنا تلقائياً بعد الاتصال.)

## التحكم
1. تبويب «هاتف التحكم»: ستظهر الأجهزة القريبة تلقائياً (📶 واي فاي / 🔵 بلوتوث) — اضغط جهازاً وأدخل الـ PIN مرة واحدة.
2. للبلوتوث: على هاتف الشاشة اضغط «جعل البلوتوث قابلاً للاكتشاف» أو اقرنهما مسبقاً من إعدادات النظام.
3. أزرار الشريط العلوي: ✎ تعديل/لعب • ＋ إضافة زر • 👁 إخفاء • ⚙ إعدادات • ✕ خروج.

## ملاحظات
- جرّب Wi-Fi أولاً؛ البلوتوث أبطأ قليلاً لكنه لا يحتاج شبكة.
- بعض الراوترات تمنع التواصل بين الأجهزة (AP isolation) — حينها استخدم هوتسبوت أو البلوتوث.
- المنافذ: TCP 5555 و UDP 5556.
